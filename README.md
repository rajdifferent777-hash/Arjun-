# Skybound Relic

An original Android-first 3D endless runner built around a living route: ancient stone ruins, luminous energy structures, branching risk/reward lanes, escalating pursuit, and procedural replayability.

## Current foundation
- Godot 4 project
- Mobile-friendly GL Compatibility renderer
- Original procedural-art direction; no third-party game assets
- Keyboard controls for desktop development
- Touch input architecture planned for the vertical slice

## Build order
1. Playable 3D movement and camera
2. Procedural route chunks with solvability validation
3. Coins, obstacles, risk/reward lanes
4. Pursuer and mistake-based chase pressure
5. Power-ups and game-feel feedback
6. HUD, progression, saving and missions
7. Mobile optimization and Android export verification

## Quality rule
Features are only considered complete after they are implemented, reviewed, and verified in an executable environment. GitHub stores the source; an actual Godot/Android build environment is still required for runtime/export verification.
